## 2026-05-21 - [Homepage Data Caching Pattern]\n**Learning:** The default cache driver in this environment is `file`, which does not support cache tags. Cache invalidation for multi-model views must rely on specific cache keys managed manually via `Cache::forget()` in model events.\n**Action:** Always verify cache driver capabilities via `Cache::getStore() instanceof \Illuminate\Cache\TaggableStore` when planning cache invalidations, and fallback to direct key invalidation hook setup inside `AppServiceProvider::boot`.
