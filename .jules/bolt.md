## 2026-05-25 - Laravel Caching of Cast Arrays without N+1
**Learning:** In Laravel, caching an Eloquent model that relies on an attribute which is explicitly cast in the model (e.g., `protected $casts = ['technologies' => 'array'];`) does not require eager-loading (`with()`) before caching to avoid N+1 query problems. The JSON object is inherently retrieved and stored within the single primary model array. A reviewer might suggest ensuring relationships are eager-loaded, but if the attribute is actually a cast attribute instead of a true relational model, eager loading will cause errors.
**Action:** When evaluating caching strategies and code review comments regarding eager loading, meticulously inspect the model definition to verify whether properties (like `technologies`) are distinct database relations (`hasMany`, etc.) or simply casted JSON columns. Apply `with()` only for genuine relational data.
