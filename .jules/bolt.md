## 2024-06-29 - [Pagination Caching and DoS Vulnerability]
**Learning:** Do not replace native Eloquent database pagination (e.g., `paginate()`) with `get()` to fetch all records into memory for the sake of caching. While trying to fix an unbounded cache growth issue (where a user can cache millions of empty pages by manipulating the `?page=` parameter), using `get()` and then `Collection::forPage()` causes severe memory exhaustion.
**Action:** Stick to native database pagination for large/unbounded datasets and avoid caching them dynamically by query parameters unless strictly bounded. For mostly static, small lists (like featured projects on a homepage), caching the entire collection is fine. Also, ensure you do not commit ephemeral cache files (e.g., `storage/framework/cache/data/`).
