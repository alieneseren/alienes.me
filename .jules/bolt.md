## 2025-04-09 - Caching Multiple Eloquent Queries in Laravel
**Learning:** When a controller fetches multiple distinct but relatively static datasets for a single view (like the home page fetching profile, experience, education, skills, and projects), it's highly efficient to package them all into a single array and cache the entire structure under one key. Relying on individual model caches fragments invalidation logic and requires multiple cache lookups.
**Action:** Consolidate multiple queries in hot paths (like the index route) into a single array via `Cache::remember`. Then use a generic invalidation trait attached to all relevant models to clear this singular cache key via `static::saved` and `static::deleted` events. This keeps logic DRY and guarantees cache coherence without relying on complex tags (especially crucial when the underlying driver might be `file` and lacking tag support).
