## 2023-10-27 - Layout Sorgularında Veritabanı Optimizasyonu
**Learning:** Laravel'de `count() > 0` yerine `exists()` (LIMIT 1) kullanımı tablolardaki tam sayım maliyetini ortadan kaldırarak veritabanı yükünü düşürüyor. Ayrıca Layout dosyası gibi sık render edilen yerlerde birden fazla veritabanı kontrolünü tek bir Array altında toplayıp `Cache::remember()` kullanmak gereksiz yükleri engelliyor. Ancak View seviyesindeki önbellekleme, cache invalidation olmadan 1 saat (3600) gibi uzun sürelerde uygulandığında güncellenen verilerin (örn: CV'nin gizlenmesi) zamanında yansımamasına (stale data) neden oluyor.
**Action:** Layout gibi MVC dışında yapılan cache optimizasyonlarında TTL (Cache Invalidation yoksa) 60 saniye gibi düşük tutulmalı veya Model boot metotlarında ilgili cache anahtarları temizlenmelidir.
