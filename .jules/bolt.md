## 2024-05-15 - Unintentional Artifact Tracking during Testing
**Learning:** Running temporary backend testing scripts that utilize the default `file` cache driver or missing mocked views generates local binary blob artifacts in `storage/framework/cache/data/` and `storage/framework/views/` that Git automatically stages if not carefully excluded or if `git add .` is inadvertently executed. The same goes for `.log` files when executing queries that generate errors. Build commands (`npm run build`) can also modify `package-lock.json` unexpectedly.
**Action:** Always strictly review `git status` before committing. Exclude `storage/` and dynamically generated artifacts by using precise `git add <file>` operations instead of broad strokes, and aggressively clean untracked artifacts using `git restore --staged <path> && git checkout <path>` and `git clean -fd storage/`.
