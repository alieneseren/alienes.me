## 2024-05-31 - Cache Optimization and Fallback Strategy
**Learning:** This repository defaults to a `file` cache driver which does not support cache tagging. When attempting to invalidate multiple related models (like those on the homepage), creating a single consolidated cache array and invalidating it via model events (`saved`, `deleted`) provides a highly effective workaround for tagless environments. Also, `php artisan tinker` combined with manual DB schema creation on SQLite is an effective way to test these cache behaviors when PHPUnit and default migrations are unusable.
**Action:** Always verify cache driver capabilities before implementing tag-based strategies. For combined pages like homepages, fetch all data in one grouped query and cache the resulting array, then attach invalidation listeners to the `boot` method of the application service provider for related models.
