## 2025-02-12 - HomeController Caching and Boot Events
**Learning:** In Laravel portofolio/CV apps, the home page often makes numerous unnecessary DB queries to unchanging model data (Profile, Experience, Education, Skills, Projects). Caching this directly in the controller reduces significant overhead. However, the models must clear this cache upon being updated or deleted so visitors aren't seeing stale data. The `AppServiceProvider`'s `boot` method provides a centralized location to hook into these model events without having to create separate Observers for each.
**Action:** When working on similar Laravel portofolio applications, apply proactive caching using `Cache::rememberForever` in the controller paired with Model event listeners `saved` and `deleted` within a ServiceProvider.
